# PRIMARY SOURCES

1. **The Dragon Hatchling paper / BDH-CQ Technical Report**
   - **Claims Supported**: BDH architectures utilize brain-inspired continuous latent mechanisms; BDH-CQ learns to reason from demonstrations without written chain of thought.
   - **Context**: Used as the primary theoretical foundation for the latent vs written CoT distinction in the educational module.

2. **From Attention to Synapses: Deriving BDH**
   - **Claims Supported**: Architectural differences between Transformer self-attention and BDH recurrent state representations.
   - **Context**: Supports the conceptual diagram showing iterative state updates (`h_(t+1) = f(h_t, x)`).

3. **Official Toy BDH Implementation** (Educational Abstraction)
   - **Claims Supported**: Illustrates how a latent vector can be repeatedly transformed before emission.
   - **Context**: Used to inspire our "Toy Reimplementation" interactive visualizer.
